# Editing Decisions

These fictional examples demonstrate decisions, not fixed replacement templates. Use only facts provided by the actual task.

| Situation | Before | Revision and decision |
|---|---|---|
| Confirmed feature | “This tool is designed to potentially help you group receipts by supplier.” | “Group receipts by supplier.” Remove empty hedging around known behavior. |
| Redundant caveat | “Here is the summary. Please note this is only a summary and does not include every detail.” | “Here is the summary.” Remove an obvious qualification unless a specific omission matters. |
| Unmeasured benefit | “Guaranteed to cut your review time in half.” | “Review changes side by side.” Narrow to a confirmed capability; do not retain invented results. |
| Material uncertainty | “The migration may take 2–4 hours, depending on file size.” | Keep if that is the supported estimate. Concision must not turn it into a guarantee. |
| External processing | “For transparency, it is important to note that files might leave your device.” | “Uploaded files are processed by Acme.” Make specific only if Acme is the known processor. |
| Unsent message | “Everything is taken care of.” | “The email is ready for review.” Keep the action boundary. |
| Unknown failure cause | “The upload probably failed because your connection dropped.” | “The upload failed.” Add a recovery step only when supported. |
| Needless distinction | “Click Save. This saves the document; it does not publish it, email it, or change your account.” | “Click Save.” Remove irrelevant negatives unless publication confusion is part of this task. |
| Real approval gate | “Draft agreement — awaiting approval.” | Keep when approval is required before use. The word “draft” is not banned. |
| Good brand voice | “Big ideas. Small notebook.” | Keep. Do not flatten purposeful rhythm into a generic product description. |
| Useful technical detail | “Tests pass locally; the database migration has not run in staging.” | Keep in a release handoff. It changes the next action. |
| Excess nuance | “In a broad sense, and depending on how one defines a folder, you could think of this as a way to organize files.” | “Use folders to organize files.” Remove distinctions that do not affect the explanation. |
