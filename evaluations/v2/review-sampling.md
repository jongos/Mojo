# Follow-up review samples

Chosen before remaining-case judgments: split the main remaining-case review into the first 24 and last 24 cases in corpus order. Use separate fresh reviewers, with no condition maps. Each case still receives one primary review of all four outputs.

For the independent reversed-order review, select held-out cases 06 and 10 from each family: S06, S10, D06, D10, C06, C10, V06, V10, M06, M10, F06, F10. This is a systematic coverage sample, not a random sample or statistical power calculation. Together with the full pilot reversal, 24 of the 60 cases receive a second review.

The second-pass editing sample uses eight pilot outputs: S01, S02, D01, V01, V02, M01, M02 and F01. These cover short edits, a long document, voice, meaning and protected content. Conversation-generation tasks are excluded because presenting an already generated status update as new source text would change their task. D02 and F02 are excluded because the pilot already identified possible corrections; this sample asks whether successful edits remain stable. The sample is deliberately conditional on pilot success, not an estimate across all outputs.
